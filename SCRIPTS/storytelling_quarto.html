Diseño Muestral Complejo

¿Por qué diseño muestral complejo?

ENAHO usa un diseño estratificado bietápico — ignorarlo produce estimaciones sesgadas.

Código R — Diseño muestral

Code 
library(survey)


#----------------
df_p <- data.frame(
  Provincia = sprintf("%02d", 1:9),
  NAME_2 = c("Huancayo", "Concepción","Jauja", "Junín", "Tarma",
             "Yauli","Satipo","Chanchamayo","Chupaca")
)

df<-read_dta("Enaho_Empleo_Resumen_05.dta")

data<- df %>% filter(grepl("^12",df$ubigeo))%>% 
  select(ing_net,ubigeo,conglome,ocupinf,fac500a,estrato) %>% 
  mutate(Provincia=substr(ubigeo,3,4)) %>% 
  left_join(df_p)

# Declarar diseño muestral
dsg <- svydesign(
  ids     = ~conglome,  # UPM
  strata  = ~estrato,   # estratos
  weights = ~fac500a,   # factor expansión
  data    = data
)

# Estimaciones ponderadas
svymean(~ocupinf, dsg)  # → 82%
svymean(~ing_net,  dsg) # → S/. 844

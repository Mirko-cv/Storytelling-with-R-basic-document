# Storytelling with R  
Los siguientes apuntes son de un par de sesiones dirigidas a estudiantes universitarios de como usar R para lograr comunicar efectivamente un mensaje pudiendo ser una oportunidad o un problema.  
Se usan datos reales que fueron usando con anterioridad para algun proyecto de análisis de datos.  
El objetivo es reconocer el potencial de R usando sus librerias más famosas como ggplot2 y dplyr para poder encontrar el equilibrio entre mensaje, comunicación y dato.  

* Sesión 1: Caso precios de establecimientos de venta de combustible comunmente conocidos como grifos
* Sesión 2: Caso eficiencia en el mercado de agua potable y saneamiento
* Plus: Estimación de estadisticos para muestras complejas usando data de la summaris del INEI
